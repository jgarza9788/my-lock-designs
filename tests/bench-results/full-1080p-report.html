How hard each lock screen works the machine

Every design runs alone in a 1920×1080 window for 3 s of warm-up and 8 s of sampling. CPU is a percent of one core, GPU a percent of one GPU engine. Both axes below are logarithmic, because the spread runs from 0 to over a whole core.

Target: 10% CPU and 6% GPU or less. Limit: 35% CPU and 10% GPU. Memory limit: 320 MB. Designs that process the wallpaper (Terminator, Frost) are measured with one.
